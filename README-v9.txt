注音發聲板 v9－完整音節引擎版

本版重點
1. 注音字庫已從 app.js 獨立為 zhuyin-dictionary.js。
2. 內建 407 組國語基本注音拼合法作為輸入/預測引擎基礎。
3. 保留 v8 的常用候選字與 AAC 優先字。
4. 支援一聲、二聲、三聲、四聲、輕聲的候選查找與回退。
5. 支援未完成注音的提前候選。
6. 保留常用語長按儲存、整句發聲、刪除、一聲紅點等既有功能。

GitHub 更新時請同時上傳：
- index.html
- app.js
- sw.js
- zhuyin-dictionary.js

注意：
「完整音節引擎」指拼音組合/聲調處理架構完整化；
候選漢字仍採 AAC 常用字優先，並非重製教育部完整辭典。
